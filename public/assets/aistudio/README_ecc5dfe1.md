# UniBus Web

Projeto acadêmico da disciplina **PRG04 - PW**.


## Estrutura do projeto

```
unibus-web/
├── index.html                  → página inicial (marco de nascimento do projeto)
├── favicon.svg                 → ícone exibido na aba do navegador
├── README.md                   → este arquivo
├── assets/
│   ├── css/
│   │   ├── global.css          → CSS externo compartilhado por todo o projeto
│   │   │                          (paleta, tipografia, menu/nav, responsividade)
│   │   ├── sandbox.css         → CSS externo exclusivo da página SandBox
│   │   └── paleta.css          → CSS externo exclusivo da página Paleta de Cores
│   ├── js/
│   │   ├── imagem-dinamica.js  → script que troca a imagem da atividade-3
│   │   └── menu.js             → script do menu de navegação (abrir/fechar no mobile)
│   └── images/
│       ├── rota-manha.svg      → imagens usadas no recurso de imagem dinâmica
│       ├── rota-tarde.svg
│       └── rota-noite.svg
└── pages/
    ├── atividade-3.html        →  (semântica, lista, imagem dinâmica)
    ├── paleta-cores.html       →  (paleta de cores e fontes)
    └── sandbox.html            →  (áudio, vídeo, CSS externo)
```
