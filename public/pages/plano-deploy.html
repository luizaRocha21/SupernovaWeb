Plano Passo a Passo de Implantação

1

Passo 1: Banco de Dados no Supabase (PostgreSQL)

O Supabase hospeda gratuitamente o banco relacional PostgreSQL que substitui o MySQL local.

  1. Entre em https://supabase.com com sua conta do GitHub e crie um novo projeto (região: South America - São Paulo).
  2. Abra o menu SQL Editor → New Query, cole todo o conteúdo do arquivo /supabase/schema.sql e clique em Run.
  3. Copie a string JDBC no botão Connect → Transaction Pooler (porta 6543):
DB_URL=jdbc:postgresql://aws-0-sa-east-1.pooler.supabase.com:6543/postgres?sslmode=require&prepareThreshold=0 DB_USER=postgres.SEU_PROJECT_ID DB_PASSWORD=SUA_SENHA_DEFINIDA_NO_SUPABASE
2

Passo 2: Backend Java 21 Spring Boot no Render

Toda a pasta /backend-java já está pronta com Dockerfile, driver PostgreSQL no pom.xml, CORS liberado e serviço meteorológico real OpenMeteoFonteDadosClimaticosService.java.

  1. Suba o conteúdo de /backend-java no seu repositório de backend no GitHub.
  2. No https://render.com, clique em New + → Web Service e conecte esse repositório.
  3. O Render identificará automaticamente o Dockerfile. Configure as variáveis de ambiente: DB_URL, DB_USER, DB_PASSWORD, JWT_SECRET, CLIMA_FONTE=open-meteo e ALLOWED_ORIGINS=https://supernovaweb.vercel.app.
3

Passo 3: Frontend (supernovaweb) na Vercel

A pasta /supernovaweb segue a mesma organização limpa do UniBus Web (index.html, favicon.svg, assets/css/, assets/js/, assets/images/ e pages/).

  1. Suba o conteúdo da pasta /supernovaweb para o repositório supernovaweb no GitHub.
  2. No arquivo vercel.json, coloque a URL gerada pelo seu serviço no Render.
  3. Na https://vercel.com, importe o repositório supernovaweb e clique em Deploy.
