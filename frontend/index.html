ARQUITETURA WEB SEPARADA · PASSO A PASSO DE IMPLANTAÇÃO

Guia Completo: GitHub + Supabase + Render + Vercel

1

Visão Geral da Nova Estrutura (Padrão UniBus Web)

O projeto foi organizado em duas frentes limpas e desacopladas conectadas pelo GitHub:

┌──────────────────────────────┐ HTTPS / JSON ┌──────────────────────────────┐ JDBC PostgreSQL ┌──────────────────────────────┐ │ FRONTEND: supernovaweb │ ─────────────────────────► │ BACKEND: Java 21 Spring │ ───────────────────────────► │ BANCO: Supabase Postgres │ │ (HTML + CSS + JS Responsivo)│ /api/v1/* (JWT Auth) │ (Docker + Open-Meteo API) │ Pooler SSL Porta 6543 │ (13 Tabelas + Seed Irecê) │ │ Hospedado na VERCEL │ ◄───────────────────────── │ Hospedado no RENDER │ ◄─────────────────────────── │ Hospedado no SUPABASE │ └──────────────────────────────┘ └──────────────────────────────┘ └──────────────────────────────┘
2

Passo 1: Configurar o Banco de Dados no Supabase (PostgreSQL)

  1. Acesse https://supabase.com, entre com sua conta do GitHub e clique em New Project.
  2. Escolha o nome manejo-caatingueiro-db, defina uma senha forte para o banco (guarde essa senha!) e selecione a região South America (São Paulo).
  3. Assim que o banco iniciar, clique em SQL Editor no menu lateral esquerdo, clique em New Query, cole o conteúdo do arquivo /supabase/schema.sql deste projeto e clique em Run. Isso criará todas as 13 tabelas e já cadastrará Irecê, Presidente Dutra, Povoados, Culturas (Milho, Mamona, Feijão, Sorgo) e as Normais Climatológicas de 30 anos!
  4. Clique no botão Connect (no topo do painel do Supabase) → aba Transaction Pooler (porta 6543) ou Session Pooler (porta 5432) → copie os dados JDBC:
    DB_URL=jdbc:postgresql://aws-0-sa-east-1.pooler.supabase.com:6543/postgres?sslmode=require&prepareThreshold=0 DB_USER=postgres.SEU_PROJECT_REF DB_PASSWORD=SUA_SENHA_DO_SUPABASE
3

Passo 2: Hospedar o Backend Java no Render.com

  1. No seu repositório do backend no GitHub (ex: Supernova), mantenha os arquivos da pasta /backend-java na raiz (Dockerfile, render.yaml, pom.xml e src/).
  2. Acesse https://render.com, faça login com seu GitHub e clique em New + → Web Service.
  3. Selecione o repositório do Backend no GitHub. O Render detectará automaticamente o Runtime: Docker (usando o Dockerfile com Maven + Java 21 já pronto).
  4. Na seção Environment Variables do Render, adicione as variáveis abaixo:
Variável no RenderValor
PORT8080
DB_URLjdbc:postgresql://aws-0-sa-east-1.pooler.supabase.com:6543/postgres?sslmode=require&prepareThreshold=0
DB_USERpostgres.SEU_PROJECT_REF (copiado do Supabase)
DB_PASSWORDSua senha do banco no Supabase
JWT_SECRETmanejo-caatingueiro-chave-secreta-jwt-ifba-irece-2026 (mínimo 32 caracteres)
ALLOWED_ORIGINShttps://supernovaweb.vercel.app,http://localhost:3000
CLIMA_FONTEopen-meteo (ativa a busca real de chuva de Irecê e Presidente Dutra)
BOOTSTRAP_GESTOR_TELEFONE74999990000
BOOTSTRAP_GESTOR_SENHAsenha123

Ao finalizar o deploy, o Render fornecerá uma URL pública como: https://manejo-caatingueiro-api.onrender.com.

4

Passo 3: Hospedar o Frontend (supernovaweb) na Vercel

  1. No seu repositório GitHub supernovaweb, suba exatamente o conteúdo da pasta /supernovaweb deste projeto:
    supernovaweb/ ├── index.html ├── favicon.svg ├── vercel.json ├── README.md ├── assets/ │ ├── css/ (global.css, painel.css, comunidade.css) │ ├── js/ (menu.js, clima-dinamico.js, app.js) │ └── images/ (logo.png, logo-mark.svg, roca-favoravel.svg, roca-atencao.svg, roca-estiagem.svg) └── pages/ ├── plantio.html ├── reservatorios.html ├── comunidade.html └── plano-deploy.html
  2. No arquivo vercel.json da raiz do supernovaweb, aponte o destino do proxy para a URL do seu Render:
    { "version": 2, "cleanUrls": true, "rewrites": [ { "source": "/api/v1/:path*", "destination": "https://SEU-SERVICO-NO-RENDER.onrender.com/api/v1/:path*" } ] }
  3. Acesse https://vercel.com, entre com seu GitHub, clique em Add New → Project e importe o repositório supernovaweb.
  4. Em Framework Preset, deixe como Other (HTML/CSS/JS estático) e clique em Deploy. Em menos de 15 segundos seu site estará no ar com HTTPS, responsivo para celular e computador e conectado ao Render + Supabase!
